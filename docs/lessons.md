# web — Lessons Learned

> **Moved.** Lessons are now one file each under [`docs/lessons/`](lessons/_index.md),
> so a session can load the index without loading the corpus.
>
> **Writing a new lesson? Do NOT append here.** Create
> `docs/lessons/lesson-NNN-<slug>.md` at the next free number and add its row to
> [`docs/lessons/_index.md`](lessons/_index.md). The format is in
> [`docs/lessons/_format.md`](lessons/_format.md). Appending to this file recreates the
> monolith on top of the pointer.
