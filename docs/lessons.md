# web — Lessons Learned

> **Moved.** Lessons are now one file each under [`docs/lessons/`](lessons/),
> so a session can load one lesson without loading the corpus.
>
> **Writing a new lesson? Do NOT append here.** Create
> `docs/lessons/lesson-NNN-<slug>.md` at the next free number and run `dotf lessons fmt`.
> [dotf](https://github.com/mlorentedev/dotfiles) renders an index with `dotf lessons index`. The format is in
> [`docs/lessons/_format.md`](lessons/_format.md). Appending to this file recreates the
> monolith on top of the pointer.

**[Browse all lessons](lessons/)**

This stub stays so existing citations to `docs/lessons.md` keep resolving. To find a
lesson cited by date, grep the tree:

```bash
grep -rl "2026-07-10" docs/lessons/
```
